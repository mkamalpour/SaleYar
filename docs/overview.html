BEFORE YOU BEGIN

The questions worth asking.

Clear expectations make a better first session—and a better presentation.

Does it know my exact current stock?

Only to the extent supported by opening stock and complete transaction history. A sales-only export is not a complete inventory ledger.

Do I need an LLM?

No. Core invoice analysis and planning work without one. The advisor can use keyword support; a language-model endpoint is optional.

Can it work for a small shop?

The pipeline adapts to available history and reports limited support. Sparse records still limit the reliability of demand and risk estimates.

What is a purchase suggestion?

It is the result of the selected goal, budget and modelling assumptions—not a guarantee of sales, profit or stock availability.

The owner HTML opens without working data. What should I check?

Start python run.py --mode owner and use its served URL. Opening ui/owner.html directly bypasses its local API and assets. Check the API status and recognized invoice columns before rerunning analysis.
